# 弹窗工位宠

单文件离线摸鱼养成。右下角一只小狗或小猫（QQ 宠物风）：喂食、清便便、洗澡、猜拳、睡觉；背雅思向单词按个数长大，并回一点状态条。Esc 切到可编辑的假 Excel / 邮件。

## 怎么玩

1. 下载 [`index.html`](./index.html)
2. 双击用浏览器打开，**不需要联网**
3. `Esc`：老板键（假工作界面，仍可背单词）

## 规则摘要

- 成长按岁数；每过 1 个词加快天数
- 需求条掉得比较慢；背单词会回饥饿 / 清洁 / 心情 / 健康 / 精力
- 存档只在本机 `localStorage`，不上传、不采集
- 形象可在开局或「显示属性」里选小狗 / 小猫
