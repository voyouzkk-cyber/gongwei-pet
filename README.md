# 弹窗工位宠 / Desk Ad Pet

**中文** · 单文件离线摸鱼养成。右下角一只小狗或小猫（QQ 宠物风）：喂食、清便便、洗澡、猜拳、睡觉；背雅思向单词按个数长大，并回一点状态条。`Esc` 切到可编辑的假 Excel / 邮件。

**English** · A single-file offline desk pet. A dog or cat (QQ-pet style) sits in the corner: feed, clean, bathe, rock-paper-scissors, sleep. Type IELTS-style English words to grow and refill status bars. `Esc` switches to a fake editable Excel / mail “boss mode.”

---

## 怎么玩 / How to play

1. 下载 [`index.html`](./index.html) / Download [`index.html`](./index.html)
2. 双击用浏览器打开，**不需要联网** / Open in a browser — **no network required**
3. `Esc`：老板键（假工作界面，仍可背单词） / Boss key (fake work UI; typing can still earn)

## 规则摘要 / Rules

| 中文 | English |
| --- | --- |
| 成长按岁数；每过 1 个词加快天数 | Age by “years”; each correct word advances time |
| 需求条掉得慢；背单词回饥饿/清洁/心情/健康/精力 | Needs decay slowly; typing refills hunger/clean/mood/health/energy |
| 存档只在本机 `localStorage`，不上传、不采集 | Save only in local `localStorage`; nothing uploaded |
| 开局或「显示属性」可选小狗 / 小猫 | Pick dog or cat at start or in stats |
